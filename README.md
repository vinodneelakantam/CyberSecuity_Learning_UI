# CyberSecuity_Learning_UI

Interactive HTML learning tool for explaining SecurityStorage internals in an ADAS automotive embedded context.

**Live demo:** https://vinodneelakantam.github.io/CyberSecuity_Learning_UI/

Now includes dropdown-driven scenarios for:
- SecurityStorage
- SecureJTAG
- SecureDiagnostics
- SecureBoot
- SecureLogging

Platform selector options:
- TDA4VM (Jacinto7)
- Jacinto7 Generic

## Run

Open `index.html` directly in a browser.

## Contents

- `index.html`: Page structure and technical content
- `styles.css`: Visual design, responsiveness, and animations
- `script.js`: Interactive playback, tabs, learning mode, glossary search, and quiz logic
